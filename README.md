# Cup & Corner

Адаптивный лендинг для кофейни, созданный как портфолио-проект для Kwork.

## Что внутри

- React + Vite
- Обычный CSS без UI-фреймворков
- Данные меню в отдельном файле `src/data/menu.js`
- Компоненты для меню и формы бронирования
- Валидация формы на клиенте
- Сообщение об успешной отправке заявки
- Адаптивная верстка для мобильных устройств

## Секции

- Главный экран
- О кофейне
- Меню
- Популярные позиции
- Акция
- Галерея интерьера
- Отзывы
- Бронирование столика
- Контакты и карта-заглушка

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
