# Cup & Corner

Cup & Corner - это адаптивный лендинг для уютной кофейни. Проект сделан как пример коммерческого сайта: с красивым первым экраном, меню, популярными позициями, галереей интерьера, отзывами, контактами и формой бронирования столика.

Сайт подходит как основа для кофейни, пекарни, небольшого кафе, кондитерской или другого локального заведения, которому нужна понятная посадочная страница.

## Что есть на сайте

- Главный экран с названием, слоганом и кнопками к меню и бронированию.
- Блок о кофейне с преимуществами.
- Меню с категориями: кофе, десерты и завтраки.
- Популярные позиции с локальными фотографиями.
- Акция для гостей.
- Галерея интерьера.
- Отзывы клиентов.
- Форма бронирования столика.
- Контакты, часы работы, телефон и карта-заглушка.
- Мобильное меню.
- Кнопка "Наверх".

## Форма бронирования

Форма собирает:

- имя;
- телефон;
- дату;
- время;
- количество гостей;
- комментарий.

В форме есть простая валидация: нельзя отправить пустые обязательные поля, некорректный телефон или дату в прошлом. После успешной отправки появляется модальное окно с подтверждением заявки.

В демо-версии заявка не отправляется администратору, потому что проект сделан без backend. По запросу можно подключить отправку заявок на email, в Telegram или в отдельную админ-панель.

## Технологии

- React
- Vite
- Обычный CSS
- JavaScript
- Данные меню вынесены в отдельный файл `src/data/menu.js`

## Как запустить проект

```bash
npm install
npm run dev
```

Если запуск идёт через PowerShell на Windows и обычная команда `npm` не работает, можно использовать:

```powershell
& "D:\node js\npm.cmd" run dev
```

## Как собрать проект

```bash
npm run build
```

## Что можно доработать под реального клиента

- Подключить отправку заявок на email.
- Подключить Telegram-уведомления для администратора.
- Заменить тексты, цены, адрес и фотографии.
- Добавить настоящую карту.
- Подключить аналитику.
- Добавить админ-панель для управления меню и заявками.

## Статус проекта

Это готовый frontend-лендинг без backend. Его можно использовать как портфолио-проект или как основу для небольшого коммерческого сайта.
